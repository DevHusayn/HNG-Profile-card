# HNG Profile Card

This is my **Profile Card Project** for the HNG Internship.  
It showcases my basic HTML, CSS, and JavaScript skills in creating a responsive and well-structured profile component.


## 🧠 Features
- Responsive profile card design  
- Displays user’s name, bio, and avatar  
- Shows current time (in milliseconds) dynamically  
- Includes social media links (LinkedIn, X, GitHub)  
- Lists hobbies and dislikes  


## 🛠️ Technologies Used
- **HTML5** — semantic structure  
- **CSS3** — responsive layout and styling  
- **JavaScript (ES6)** — dynamic content updates
